# Repository Instructions

This repository is the Next.js App Router implementation for I Love Word Search.

- Keep the app in Next.js, TypeScript, and Tailwind CSS.
- Keep indexable editorial pages server-rendered/static where possible.
- Keep the builder as the only broadly hydrated surface.
- Preserve deterministic puzzle generation across preview, print, answer key, share, QR, and utility pages.
- Do not reintroduce Remix, React Router app routes, Vite server entrypoints, or generated build artifacts.
- Avoid medical or cognitive-health claims unless sourced and intentionally added later.
