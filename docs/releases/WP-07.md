# WP07 — Editorial quality safeguards

**Branch:** `release/2026-W46-editorial-safeguards`  
**Base:** `release/2026-W46-direction-validation` (`c6539992f95ea584498329bc319ac38edbbe160e`)

## Change

- Added a publication checklist separating human editorial decisions from structural automation. It covers puzzle/direction consistency, sourced factual and health/learning claims, review date provenance, teacher-facing correctness, answer paths, output consistency, audience suitability, and copyright-sensitive topics.
- Updated content operations and architecture guidance to require the checklist before editorial publication.
- Strengthened the content audit so published puzzle, collection, and guide records require a real, non-future `YYYY-MM-DD` review date; supplied dates are validated on every record.
- Added structural errors for missing, invalid, or duplicate word-search direction keys. Invalid direction records are excluded only from generated-grid fingerprint calculation, so the audit can report the fatal structural error without throwing before it returns the error list.
- Extended the 150-puzzle publication test to confirm the actual generated request retains each curated difficulty, grid dimensions, and configured directions; that every authored word is placed; and every placement path matches the generated grid. Existing tests continue to check all 150 fingerprints, answer paths, PDF readiness, and share-state reproduction.

No editorial page copy, puzzle seed, word list, review date, grid, placement, URL, or publication status was changed. No automated claim keyword ban was added; semantic truth and pedagogical suitability remain human-reviewed to avoid false positives and unsupported approvals.

## Human-review limits

Automated checks cannot establish factual accuracy, whether prose is misleading, whether a word/definition is correct for a particular grade band, or whether an activity is pedagogically suitable. Those are explicitly required human gates in `docs/content-review-checklist.md`. WP03 remains responsible for implementation-level student instruction correctness; this package adds the review workflow and the editorial data checks without changing puzzle generation or authored copy.
