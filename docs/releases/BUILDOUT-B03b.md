# B03b / U11 / T27 — guest classroom pack workflow

Status: draft review checkpoint, not approved or deployed. Base `283af52e9a9b0e2fcf2417de970c6db3efe8c303` (draft PR #19), branch `release/2026-W46-pack-builder`, targeting `release/2026-W46-print-packs`. See the draft PR for this record's containing commit SHA. The source engine and its separate release evidence remain in the parent PR.

The unlinked `/pack-builder` utility has noindex HTML metadata, a scoped noindex response header, and no sitemap entry. It uses client-only assignment creation and the existing PDF pack renderer; input is not sent to an API. The browser fetches static application chunks from the same origin as needed. The 5/10 sheets use the same supplied vocabulary with reproducible assignment IDs 01–05 or 01–10 and derived seeds, followed by or interleaved with matching answers. The first five assignments are identical across pack sizes. English Latin input, one puzzle per portrait page, fixed 15×15 medium-direction grids and ink-saving output are intentional current limits; the output is not strictly black/white. No sign-in, preset persistence, advertising, indexed content or staged Christmas sets were introduced.

Inputs are neither rewritten nor silently dropped. Title is limited to 20 characters to protect the existing PDF name/date area, and a conservative word-bank width preflight rejects lists that may exceed its two reserved rows. This blocks some valid-looking lists and many staged Christmas titles; those sets are not integrated or ready for publication. Further PDF title/word-bank measurement, print legibility review and content-specific compatibility are required before that integration. The interface states the limits. Empty, invalid, duplicate normalized/token-identical, unsupported, overlong, unplaced and too-wide lists fail with retained entries; export failures also retain entries. Generator and single-puzzle output behavior are unchanged. The current preflight is conservative, not a universal typography or printer certification.
