# Zero-placement definition recovery

Review-only semantic validation change. Definitions that previously produced a filler-only grid with zero placed answers are now invalid. Existing valid requests, generator attempts/PRNG/filler behavior, published fingerprints and advertising remain unchanged.

The shared request validator rejects lists with no supported unique answers or no answer that geometrically fits a selected direction's grid span. Omitted difficulty presets include horizontal and vertical directions; explicit directions honor rectangular dimensions. Existing workload limits retain precedence. Because bounded seeded attempts can still miss all valid positions, generation also checks the actual placed count before filling unused cells and throws an actionable seed/configuration error if none placed. It never retries, changes the PRNG sequence or substitutes a fallback grid.

The maker catches generation failures, keeps known semantic errors editable and blocks stale output actions. Initial missing clues and blank seeds also retain their editable fields. Automatic last-builder caching and its last-valid restoration reference update only after successful generation, preserving the previous valid puzzle after a seed-specific miss. Shared play/print/PDF/answer routes use the same validator and generation guard; bounded schema-valid semantic failures offer an explicit, nonprefetched Edit this puzzle link retaining the original encoded input. Malformed, opaque and oversized definitions retain generic recovery. Synthetic zero-placement PDF objects fail the PDF boundary too. Partially fitting requests retain their existing exclusions/warnings.

Migration: old empty, unsupported-only, geometrically impossible or zero-placement seeded definitions no longer open as playable puzzles. They can be corrected explicitly in the maker. A named-library record failing definition validation makes the stored library invalid; it is preserved and never silently rewritten or deleted. A schema-valid seed-specific miss can still remain in the library and opens the maker's editable generation error. No valid historical definition is intentionally migrated.

Targeted78 semantic/request/content-audit/staged/clue tests and lint/typecheck pass before final production/browser checks. A recorded40x40/SE/40-letter seed-specific miss now fails centrally; its valid neighboring seed retains exact prechange grid and placement SHA256 values. Invalid content records now produce an explicit generation-failed audit error instead of crashing the audit; existing duplicate and content checks continue. Original partial-exclusion tests still assert exclusions using a list with one fitting word. Physical printing and editorial approval remain separate.
