## Reproduction and bounded behavior

Before application edits, four regression cases for invalid difficulty, alphabet,
filler and word-bank values failed because the generator accepted unsupported
values. Potentially enormous grids were not allocated for the reproduction.
The full fixed suite then covers invalid dimensions/types/non-finite values and
resource limits safely, before grid allocation.

`lib/puzzle/request-validation.ts` validates without coercion, reordering,
deduplicating or dropping fields. It is shared by the generator, validated puzzle
decoder and builder. The existing raw decoder remains available to distinguish
omitted fields from deliberately empty arrays; the validated utility decoder
rejects an invalid definition. The share encoder and generation algorithm stay
unchanged. The raw decoder now rejects malformed base64, invalid UTF-8, wrong root
shapes and excessive payloads rather than repairing bytes silently.

| Boundary | Rule |
| --- | --- |
| Rows / columns | If supplied, finite integers 6–40, including when auto-size is on; manual mode requires both |
| Words / clues | At most 200 delimiter-separated entries, 16000 UTF-16 characters |
| Tokens | At most 128 per answer and 4096 in total; ordinary overlong-for-grid words still use existing exclusion behavior |
| Title / subtitle / seed | At most 256 / 500 / 256 characters; correct string types |
| Instructions / hidden message / custom filler | At most 2000 characters each |
| Directions | Nonempty supported keys, original order and duplicates retained, at most 128 entries |
| Options | Existing alphabet packs, difficulty/filler/word-bank enums; strict booleans |
| Total definition | At most 24000 UTF-8 serialized bytes; encoded state at most 32000 characters |
| Upload | Reject files over 64000 bytes before reading; decoded text then uses the same limits |
| Saved state | Bound before JSON parsing, check object shape, validate before generation; do not silently replace invalid data |

These limits define the supported UI/share configuration envelope. They preserve
all 150 published definitions, three default presets, tested old omitted-field
links and ordinary 12/20/40/100-word Unicode/ASCII links. The old permissive engine
also accepted pathological or unsupported inputs outside these bounds. Such links
now deliberately fail with an error; universal compatibility with arbitrary old
unchecked dimensions, oversized text or more than 128 repeated direction entries
is **not** claimed. This is the explicit input-boundary change authorized by WP-01,
not a migration of published puzzles or their grids.

A nine-copy `E` direction link has a pre-change PR #2 result fingerprint
`8c2052fa32c071e091a19c2e2003beaef16e515787ee84fc0d8fca3e0ea04830`.
The new test matches it exactly, including grid, placements and share path. An
initial eight-entry cap was rejected during review and expanded to preserve
bounded legacy duplicate-direction configurations. No direction normalization is
used. Large permitted configurations may still take longer than small ones; these
are finite resource limits, not a promise of instantaneous generation.

## User-facing errors and editing

Malformed external/saved definitions show an accessible error shell and explicit
recovery, without a default-grid flash. In-progress edits keep their controls and
focus: clearing/retyping a number or correcting an oversized paste must remain
possible. Blank numeric drafts are represented locally as invalid until completed;
they are never saved or encoded. Switching to auto-size explicitly restores valid
remembered dimensions. File errors can be corrected by choosing a valid file.

Generation/output is blocked whenever configuration is invalid or has not reached
the debounced committed state. No old grid, share action, SVG, print portal, PDF
dialog or QR output is presented during that interval. The utility component keeps
output preferences but blocks its portals/dialogs/QR work. The builder preserves
its preview area's height while checking an edit, so content below it does not
collapse into the reserved space. Advertising code and wrappers are untouched.
