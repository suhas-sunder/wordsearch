# WP-03 — Printable direction instructions

Base: PR #2 `release/2026-W46-direction-validation` at c6539992f95ea584498329bc319ac38edbbe160e. Independently stacked on PR #2 for review; no deployment is authorized.

The legacy generated instruction says words may run backward, up, down, or diagonally regardless of which directions are permitted. The student-facing printable and PDF now use one shared display helper that spells out each resolved permitted direction when the request contains that exact legacy default. Answer pages retain their existing answer-key message. All other authored instruction strings remain unchanged. Preview and static share utility pages use the same printable component; downloadable PDF uses the same helper. The underlying request, generated grids, placements, share encoding and URLs remain unchanged, as demonstrated by the existing 150 published fingerprints and share replay assertions.

The old default string is also present in existing serialized links. Its provenance cannot be distinguished from a user independently authoring the exact same string, so this exact string is treated as the legacy default at render time. Other user-authored instructions are not interpreted or rewritten, even if they are inaccurate; users retain responsibility for reviewing custom text. Explicit empty text is preserved. No editorial content was rewritten.
