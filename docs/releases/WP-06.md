# WP-06 — Share-link reliability investigation

Status: investigation and repeatable tests complete; independent review pending. Branch `release/2026-W46-share-reliability` is based on `c6539992f95ea584498329bc319ac38edbbe160e` (PR #2); the containing commit and PR are the review references. No production deployment or merge. Validation below predates WP-01 input bounds and should be repeated after integration.

## Findings

With the default request fields and synthetic short words, the following production-host URL lengths and QR versions were measured. Each link loaded the local static export in headless Chromium; its share dialog preserved the words and produced a QR image. Numbers are examples, not universal limits: word and other field lengths, Unicode byte count, and settings change them. The QR encoder used error correction M.

| Words | ASCII URL characters / QR | Unicode URL characters / QR |
| --- | --- | --- |
| 12 | 632 / v20 (97 modules) | 667 / v21 (101) |
| 20 | 717 / v21 (101) | 773 / v22 (105) |
| 40 | 931 / v25 (117) | 1040 / v26 (121) |
| 100 | 1572 / v33 (149) | 1841 / v36 (161) |

A second example with 1,000 CJK characters in instructions was 4,416 characters, loaded locally, exceeded the QR encoder's capacity, and displayed the share dialog's explicit QR error while retaining the link. URL length acceptance varies across browsers, applications, proxies and hosts; these results establish no portable maximum. The generated PNG is 224 pixels wide with a four-module margin: at v36 the roughly 169-module total leaves only about 1.3 pixels per module. Successful PNG generation is not evidence of reliable scanning. Test printed and on-screen codes on actual devices, display sizes, and printers before claiming readability; evaluate a clear warning or alternate transport in a separately reviewed design.

Share state is URL-safe base64 JSON, not encryption. Anyone with a link can decode words, title, instructions, seed and other included settings, and URLs may be retained in browser history, logs or other recipients' systems. Avoid putting sensitive information in puzzle fields. Existing `strict-origin-when-cross-origin` referrer policy does not make a shared URL private. This investigation adds no infrastructure and does not change the payload format.
